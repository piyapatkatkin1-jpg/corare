# 🕹️ Minecraft Server Skript Integration Guide

คู่มือการติดตั้งและตั้งค่าสคริปต์ Skript สำหรับเชื่อมต่อเซิร์ฟเวอร์ Minecraft เข้ากับเว็บร้านค้า **corarevanilla Web Store**

---

## 📁 ไฟล์ที่มีให้
1. **`link.sk`**: ระบบยืนยันตัวตนและผูกบัญชีด้วยคำสั่ง `/link <รหัส 5 ตัวอักษร>`
2. **`delivery.sk`**: ระบบดึงคำสั่งซื้อสินค้าจากเว็บมาประมวลผลในเกมอัตโนมัติ (Queue Poller)

---

## ⚙️ ขั้นตอนการติดตั้ง

### 1. ปลั๊กอินที่ต้องติดตั้งบนเซิร์ฟเวอร์ Minecraft
- [Skript](https://github.com/SkriptLang/Skript/releases) (แนะนำเวอร์ชัน 2.6 หรือ 2.8+)
- [skript-reflect](https://github.com/SkriptLang/skript-reflect/releases) (แนะนำสำหรับเรียกใช้ HTTP Request โดยตรงผ่าน Java ไม่ต้องพึ่งพา addon ภายนอก)
- *(ทางเลือก)* หากใช้ [skript-http](https://github.com/Not-Just-A-User/skript-http) ให้สลับไปใช้โค้ดส่วนท้ายของไฟล์

### 2. นำไฟล์สคริปต์ไปวาง
คัดลอกไฟล์ `link.sk` ไปวางไว้ในโฟลเดอร์ของเซิร์ฟเวอร์:
```
plugins/
  └── Skript/
        └── scripts/
              ├── link.sk
              └── delivery.sk (หากต้องการใช้ระบบคิว)
```

### 3. ตั้งค่าการเชื่อมต่อ (Options)
เปิดไฟล์ `link.sk` ด้วย Text Editor และแก้ไขส่วนหัว:
```skript
options:
    backend-url: "http://<IP-เว็บของคุณ>:5000/api/link-account"
    server-secret: "corare_minecraft_secret_token_change_in_production"
    prefix: "&8[&bCorare&fVanilla&8]&r"
```
> ⚠️ **สำคัญ:** ค่า `server-secret` ต้องตรงกับค่า `SERVER_SECRET_KEY` ในไฟล์ `.env` ของโฟลเดอร์ `server` มิฉะนั้นระบบจะปฏิเสธคำขอ (403 Forbidden) เพื่อป้องกันความปลอดภัย

### 4. รีโหลดสคริปต์ในเกม
พิมพ์คำสั่งในคอนโซลเซิร์ฟเวอร์ หรือในเกม (สำหรับ OP/Admin):
```
/sk reload link
```

## 🧪 การทดสอบการใช้งาน

1. ผู้เล่นเข้าสู่หน้าเว็บร้านค้า แล้วกดปุ่ม **"เข้าสู่ระบบ / ผูกบัญชี"**
2. กรอกชื่อตัวละคร Minecraft ของตนเอง (เช่น `Notch`)
3. เว็บจะแสดงรหัสยืนยัน 5 ตัวอักษร เช่น `AJDE1`
4. ผู้เล่นเข้าเกม Minecraft แล้วพิมพ์คำสั่ง:
   ```
   /link AJDE1
   ```
5. ระบบจะขึ้นเสียงเลเวลอัป พร้อมแจ้งเตือนในแชทและไตเติลบนหน้าจอว่า **"ผูกบัญชีสำเร็จ!"**
6. หน้าเว็บร้านค้าจะตรวจจับสถานะอัตโนมัติ และเข้าสู่ระบบให้ทันทีโดยไม่ต้องรีเฟรชหน้าเว็บ!

---

## 🔒 ฟีเจอร์ความปลอดภัยที่มีให้
- รหัสยืนยันสุ่มด้วยระบบ Cryptographically Random (ป้องกันการคาดเดา)
- รหัสมีอายุ 5 นาที และใช้งานได้เพียงครั้งเดียว (Single-Use Token)
- ป้องกันการ Brute-force: หากใส่รหัสผิดเกิน 5 ครั้ง รหัสนั้นจะถูกยกเลิกทันที
- ตรวจสอบ `X-Server-Secret` ป้องกันบุคคลภายนอกยิง API แอบอ้างว่าเป็นเซิร์ฟเวอร์เกม
